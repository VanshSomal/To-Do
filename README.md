# 📝 To-Do App

🚀 Live Demo: https://vanshsomal.github.io/To-Do/

A simple and efficient To-Do application built using HTML, CSS (Tailwind), and JavaScript, allowing users to manage daily tasks with ease.

✨ Features
➕ Add new tasks
🗑️ Delete tasks
💾 Data stored in localStorage (persists after refresh)
⚡ Fast and responsive UI
🎨 Styled using Tailwind CSS
🛠️ Tech Stack
HTML – Structure
CSS (Tailwind) – Styling
JavaScript – Functionality & logic
localStorage – Data persistence
📸 Preview

👉 Try it here: https://vanshsomal.github.io/To-Do/

⚙️ How It Works
Enter a task in the input field
Click Add button
Task gets stored in browser using localStorage
Tasks remain even after refreshing the page
